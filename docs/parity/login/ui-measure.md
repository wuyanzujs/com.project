- 量测日期：2026-10-24，设备 OPPO PDEM10（1440×3168，1 设计 px = 1.92 物理 px）。
- 生产端截图：用户提供的登录页弹窗截图（手机号已填、验证码已收、协议未勾选态）。
- RN 截图：`.dpshots` 流程同机 Metro 热更新后触发「获取验证码」截取。
- 生产端文案已在 `D:/rea-targets/libapp-4.0.7.0.so` 字符串池逐句确认（UTF-16LE）：
  标题「服务协议及隐私政策」、正文两段（在线签署 / 停止注册 两段全句）、
  「点击同意即表示您已阅读并同意」「德邦快递用户协议」「德邦快递隐私政策」。

## 触发与行为（生产端）

- 手机号有效但协议未勾选时，「获取验证码」不发送验证码，弹出本弹层。
- 「同意」：勾选协议复选框，并继续弹层前被拦下的动作（继续发送验证码 / 继续登录）。
- 「不同意」/×：仅关闭弹层，不勾选、不继续动作。

## 备注

- 链接蓝 (36,88,226) 比品牌色 #1a5eff 深，新增 token `$dp-color-text-link: #2458e2`。
- 弹层底部留白不能用 `useAppSafeAreaBottomInset`：本机该值恒为 0（RN 窗口已全屏但
  safe-area-context 上报 0），与生产端 62 物理留白差 60px；改为固定 `$dp-space-32`。
- 关闭圆与行内链接的 AppPressable 有 44dp 最小尺寸/模块级样式表两个坑，见
  AGENTS.md「Taro RN 复刻布局陷阱」记忆条目：关闭圆用 96 宽外层容器右对齐补齐 44dp，
  链接文字样式必须放在 children 的内层 Text 上（`contentElement='text'` 的内部 Text
  不在调用方模块的样式表里，字号颜色全部失效）。
- RN 链接行换行点与生产差 2 字（生产在《德后断行，RN 按整词换行），两行结构一致，不追。
