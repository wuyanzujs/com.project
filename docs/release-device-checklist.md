# 真机验证清单（2026-10-22）

本轮改动里有 5 处**静态门禁覆盖不到**、必须在真机/模拟器上确认的行为。逐项打勾后再进测试包。

准备：按团队流程自行出包（本清单不涉及打包命令），确认是包含 `382a8cf` 的构建。

## 1. 列表虚拟化（5 个页面）

| 页面 | 操作 | 期望 |
| --- | --- | --- |
| 订单列表 | 连续下滑到第 3 页以上 | 滚动跟手、不出现"整页重排"的白闪；触底能继续加载；`共 N 单` 数字正确 |
| 订单列表 | 切「我寄的 / 我收的」、改日期范围、改状态筛选 | 卡片内容立即刷新（不是旧数据残留）；列表回到顶部 |
| 订单列表 | 对某单点「删除」、点「再来一单/一键回寄」 | 卡片按钮文案变「删除中 / 带入中」，完成后恢复 |
| 支付列表 | 切「待支付 / 已支付」、输入运单号搜索 | 结果正确；筛选区不再随列表滚走（这是本次的有意变化） |
| 打印订单列表 | 切「待打印 / 已打印」、切日期范围 | 计数与实际列表一致；触底加载正常 |
| 消息列表 | 进入某个分组、删除一条 | 标题栏固定不动；删除后不计入未读；空态文案正确 |
| 优惠券列表 | 切「未使用 / 已使用 / 已过期」、兑换一张券 | tab 与卡片同步；兑换成功后自动回到「未使用」并刷新 |

重点看：**快速连续切换筛选**时是否出现旧数据覆盖新数据（并发请求竞态）。

## 2. 启动流程（骨架 + 重试）

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 冷启动 | 杀掉 App 后重开 | 出现「正在加载」骨架（不再是白屏） |
| 慢网络 | 用弱网工具限速到 RTT 2s+ | 5s 内仍未就绪时会直接放行进入 App，不会卡死在启动页 |
| 启动失败 | 断网 + 清除 App 数据后启动 | 停在「启动失败，请检查网络后重试」页面，点「重试」能真正重新执行启动流程（恢复网络后能进入首页） |
| 日志 | 以上任一失败场景 | logcat / Xcode console 能看到 `[app-error] app-bootstrap: ...` |

## 3. 图标渲染（lucide 深导入）

`AppIcon` 从「包根具名导入」改成了逐个图标深导入，组件类型不变，但需要肉眼确认没有漏图或尺寸异常：

| 位置 | 期望 |
| --- | --- |
| 首页 | 功能入口图标齐全，尺寸与改前一致 |
| 「我的」页 | 头像区、设置齿轮、前进箭头（`forward` 是自绘图标）正常 |
| 订单详情 | 顶部返回、更多操作、电话图标正常 |
| 寄件页 | 扫码、相机、加减号、下拉箭头正常 |
| 弹窗/空态 | 关闭叉（`close`）、对勾（`check`）、空态插图正常 |

重点：`home` 在 0.468 版已改名 `house`，本次按新名字接入，确认底部导航「首页」图标不是空白。

## 4. 渲染异常兜底（错误边界）

| 操作 | 期望 |
| --- | --- |
| 临时在任一页面渲染期抛错（本地改代码出包） | 出现「页面加载失败」+「重新加载」按钮，不是白屏 |
| 点「重新加载」 | 重新渲染该子树；若仍失败则继续显示兜底页 |
| 日志 | 同时能看到 `[app-error] app-root: ...` 与组件栈 |

## 5. 布局微调点（本次有意改动）

| 位置 | 变化 | 期望 |
| --- | --- | --- |
| 支付列表、消息列表 | 筛选区/标题栏由「随列表滚动」改为「固定」 | 不遮挡内容、不出现双滚动条 |
| 优惠券列表 | header 顶部间距比原来多约 10dp | 与导航栏间距协调，不显拥挤 |
